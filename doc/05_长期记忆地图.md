# 长期记忆地图

本文档说明当前 SceneMemory 如何构建、更新和用于检索。

## 1. 记忆来源

SceneMemory 的来源包括：

- Habitat 当前位姿下的 RGB-D 环视。
- 远程开放词汇检测与分割结果。
- CLIP image embedding。
- 深度反投影得到的 `pos_3d / pos_2d`。
- 每轮搜索失败后的 negative feedback。
- 跨 layout / episode 的历史 object tracks。

## 2. Object Track

每个 object track 记录：

```text
obj_id
label
pos_3d / pos_2d
smoothed_pos_2d
clip_embedding
seen_count
miss_count
exist_prob
stability
last_seen_state_index
last_seen_layout_id
negative_feedback_count
cooccur_stats
```

## 3. 定位与合并

当前定位流程：

```text
mask/bbox 有效深度点
  -> 批量反投影到 world
  -> world 坐标中位数
  -> position_confidence
  -> smoothed_pos_2d
```

同批 detection 会先 consolidation：

```text
same label
distance < 0.6m
or CLIP similarity > 0.90 且距离不超过限制
```

长期 track 合并使用：

```text
高置信 detection: merge_distance 约 0.75m
低置信 detection: 可放宽到约 1.25m
episode 后 duplicate_compaction: same room + same label + 近距离 + 高 CLIP 相似
```

## 4. RoomMemory

当前 room 是 pseudo-grid room，不是真实语义房间。

默认：

```text
room_id = pseudo_room_<floor(x / 4m)>_<floor(z / 4m)>
```

每个 room 保存 object refs 和证据：

```text
seen_count
room_exist_prob
positions_2d
last_seen_state_index
negative_count
```

## 5. Negative Feedback

如果 agent 到达候选区域后仍未确认目标，会记录负反馈：

```text
candidate_reached_target_not_detected
```

影响：

- 降低 object `exist_prob`。
- 增加 `negative_feedback_count`。
- 降低 room belief。
- 后续候选排序中降低旧位置权重。

## 6. 输出文件

最终记忆：

```text
benchmark/eval/<run>/scene_memory/<scene>/scene_memory_final.json
```

阶段性快照：

```text
benchmark/eval/<run>/memory_snapshots/<scene>/*.json
```

事件流：

```text
benchmark/eval/<run>/memory_updates.jsonl
```

HTML 中的阶段性 memory timeline 使用 `memory_updates.jsonl` 回放，而不是只显示最终快照。
