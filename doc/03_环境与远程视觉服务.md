# 环境与远程视觉服务

本文档说明工作站与服务器分工、远程视觉服务启动和连通性测试。

## 1. 工作站与服务器分工

```text
工作站
  -> Habitat-Sim
  -> benchmark episode 执行
  -> SceneMemory / planning / 评测

服务器
  -> GroundingDINO
  -> MobileSAM
  -> CLIP image embedding
  -> CLIP text-image similarity
```

工作站通过 HTTP 或 SSH tunnel 访问远程服务。

## 2. 服务器端启动

常用环境变量：

```bash
export REMOTE_VISION_REPO_ROOT=$PWD
export REMOTE_VISION_DEVICE=cuda
export REMOTE_VISION_HOST=127.0.0.1
export REMOTE_VISION_PORT=8010
export REMOTE_VISION_EAGER_LOAD=1
export REMOTE_VISION_RETURN_CLIP=1
export REMOTE_VISION_CLIP_MODEL_PATH=/home/ma-user/work/zhangWei/mtu3d/data/trans/clip-vit-large-patch14
export REMOTE_VISION_CLIP_LOCAL_FILES_ONLY=1
```

启动：

```bash
bash remote_vision_server/run_server.sh
```

检查：

```bash
curl http://127.0.0.1:8010/health
curl http://127.0.0.1:8010/v1/models
```

## 4. 远程视觉客户端测试

单图检测：

```bash
python remote_vision_server/test_client.py \
  --base-url http://127.0.0.1:50220 \
  --image objects_images/Camera_01.webp \
  --prompt "camera . chair . table ." \
  --return-clip
```

CLIP 文本相似度：

```bash
python remote_vision_server/test_client.py \
  --base-url http://127.0.0.1:50220 \
  --image objects_images/Camera_01.webp \
  --prompt "camera . chair . table ." \
  --clip-texts "camera,chair,table"
```

## 5. 常见问题

- `sshpass not found`：工作站缺少 `sshpass`。
- `SSH tunnel not ready`：SSH 登录、端口或密码错误。
- `Connection refused`：远程服务未启动或端口不一致。
- `GroundingDINO ops` 报错：查看 `remote_vision_server/GROUNDINGDINO_TORCH_API_FIX.md`。
- CLIP 离线模型找不到：检查 `REMOTE_VISION_CLIP_MODEL_PATH` 是否为完整 Hugging Face 模型目录。
