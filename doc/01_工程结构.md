# 工程结构

本文档说明项目主要目录、核心模块和维护入口。

## 1. 顶层目录

```text
agent_based_method/
  benchmark/                 # benchmark schema、episode、评测与输出
  hm3d/                      # HM3D 场景与 Habitat dataset config
  objects/                   # 动态 layout 使用的 3D 物体资产
  objects_images/            # image-goal 与 VLM/CLIP 使用的物体参考图
  RAANav/                    # Agentic-RAG、长期记忆、导航与历史计划
  remote_vision_server/      # 远程 GroundingDINO/MobileSAM/CLIP 服务
  results/                   # layout 生成与场景信息中间结果
  scripts/                   # 数据集与 benchmark 辅助脚本
  doc/                       # 当前整理后的项目文档
  AgenticRAG_可执行技术规范_v1.md
  数据集基本信息.md
  工程结构说明.md
  log_filter.py
  hm3d_paths.py
```

## 2. `benchmark/`

`benchmark/` 是数据集 episode、轨迹评测和 Habitat adapter 的基础层。

关键文件：

- `benchmark/schemas.py`：定义 `Episode`、`Subtask`、`Pose`、`Trajectory` 等结构。
- `benchmark/build_episodes.py`：由动态 layout 生成 benchmark episode。
- `benchmark/evaluate.py`：根据 trajectory JSONL 计算 SR/SPL 等指标。
- `benchmark/habitat_adapter.py`：Habitat-Sim 加载、navmesh 路径和距离计算。
- `benchmark/splits/`：数据划分，例如 `benchmark_split_longterm_v1.json`。
- `benchmark/episodes/`：具体 episode JSON。
- `benchmark/eval/`：运行结果、诊断结果和可视化输出。

## 3. `RAANav/AgenticRAG/benchmark_adapter/`

这是当前真实闭环主线目录。

关键文件：

- `run_temporal_habitat_loop.py`：真实 Habitat 长期闭环主入口。
- `habitat_vision_loop.py`：封装 Habitat RGB-D 观测、远程检测和 navmesh 步进。
- `temporal_memory.py`：SceneMemory、RoomMemory、object track 更新、去重和负反馈。
- `formal_scoring.py`：RAG/Agent 融合评分。
- `episode_to_queries.py`：将 subtask 转成检索 query 和 alias。
- `image_goal_index.py`：image-goal 图像索引。
- `diagnose_temporal_run.py`：输出诊断 JSON。
- `visualize_temporal_run.py`：生成 HTML 调试页面。
- `search_video.py`：生成 subtask 级实时搜索视频。

## 4. `remote_vision_server/`

该目录用于把重视觉模型放在服务器 GPU 上运行。

关键文件：

- `server.py`：FastAPI 服务端。
- `client.py`：工作站侧 Python 客户端。
- `run_server.sh`：服务器启动脚本。
- `workstation_tunnel.sh`：SSH tunnel 辅助脚本。
- `test_client.py`：连通性、检测、CLIP embedding 和文本相似度测试。
- `README.md`：远程服务完整说明。

## 5. `results/`

`results/` 主要保存动态 layout 生成过程中的中间产物：

- `scene_info/`：场景、房间、语义实例、承载面等结构化信息。
- `probabilities/`：物体到房间或承载面的概率。
- `receptacle_queries/`：承载面查询结果。
- `object_instance_assignments/`：物体分配到具体房间/实例的计划。
- `layouts/`：最终动态 layout。

## 6. `RAANav/计划/`

该目录保存历史计划、实施记录、结果分析和命令汇总。新用户优先阅读 `doc/`，需要追溯历史时再查看 `RAANav/计划/`。
