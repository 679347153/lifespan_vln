# 评测诊断与可视化

本文档说明输出指标、诊断脚本、HTML 可视化和搜索视频。

## 1. 主要指标

- `success_rate`：benchmark 成功率，通常基于 final pose 到目标真值的距离。
- `spl`：Success weighted by Path Length。
- `found_rate`：subtask 被成功找到的比例。
- `GHR@3 / GHR@5`：候选 top-k 中是否出现接近目标的位置。
- `candidate_recall_rate`：候选层是否产生有效候选。
- `avg_final_dist`：最终位置到目标的平均距离。
- `avg_candidate_min_dist`：候选到目标的最近距离。
- `dynamic_memory_accuracy`：动态物体记忆相关准确性。

## 2. 诊断脚本

```bash
python log_filter.py --run "python -m RAANav.AgenticRAG.benchmark_adapter.diagnose_temporal_run \
  --output-dir benchmark/eval/<run> \
  --write-json benchmark/eval/<run>/diagnosis.json"
```

重点看：

```text
failure_bucket
perception_found_rate
candidate_recall_rate
ghr5_rate
ghr5_to_found_gap
avg_final_minus_candidate_min_dist
fallback_count
top labels
memory events
negative feedback
```

导航安全层诊断重点：

```text
navigation_summary.json
nav_rejected_goals
nav_clipped_goals
avg_snap_distance
max_adjacent_nav_distance
scene_outside_goal_count
nav_reject_reasons
```

其中 `requested_pose` 表示原始候选导航点，`snapped_pose` 表示投影到 navmesh 后的位置，`safe_waypoint` 表示本轮实际允许执行的局部 waypoint。若 `nav_clipped_goals` 较多，说明候选距离较远但已被安全层截断；若 `nav_rejected_goals` 较多，应优先检查候选定位、room representative 或 fallback 是否落在不可达区域。

## 3. HTML 可视化

```bash
python log_filter.py --run "python -m RAANav.AgenticRAG.benchmark_adapter.visualize_temporal_run \
  --output-dir benchmark/eval/<run>"
```

输出：

```text
benchmark/eval/<run>/visual_debug/index.html
benchmark/eval/<run>/visual_debug/visual_payload.json
```

功能：

- 2D navmesh / region / trajectory / candidates / observations。
- 3D debug 视图。
- Room Memory 树。
- Object room belief 表。
- Candidate rounds 表。
- 阶段性 memory timeline。
- 导航安全点：requested pose、snapped pose、safe waypoint 会用不同颜色标出，用于确认是否发生 snap、裁剪或拒绝。

Memory 显示模式：

```text
阶段累计
仅当前轮增量
最终快照
```

## 4. Subtask 级实时搜索视频

运行前指定录制：

```bash
--record-search-video
--video-subtasks "0:0,0:3,<subtask_id>"
--video-output-dir benchmark/eval/<run>/videos
--video-include-observation-views
--video-width 1920
--video-height 1080
```

输出：

```text
benchmark/eval/<run>/videos/<episode_id>/<subtask_id>/search.mp4
benchmark/eval/<run>/videos/<episode_id>/<subtask_id>/video_manifest.json
```

视频 Dashboard 内容：

- 左侧主画面：观测阶段显示多视角 mosaic，移动阶段显示当前第一视角 RGB。
- 右上地图：显示 navmesh / semantic region / layout objects / trajectory arrows / target / planned pose / top candidates。
- 右中规划面板：显示 planning mode、selected room、selected pose source、selected candidate 和 top-k 候选分数。
- 右下记忆面板：显示当前 round 的 memory delta、negative feedback 和最近记忆事件。
- 底部 timeline：显示 `PRE_OBSERVE -> PLAN -> MOVE -> POST_OBSERVE -> FEEDBACK -> SUMMARY` 阶段顺序。

推荐开启 `--video-include-observation-views`，否则视频仍兼容旧式单主视角显示。

注意：视频依赖 `cv2.VideoWriter`，目标运行环境需要安装 OpenCV 并支持 `mp4v`。
