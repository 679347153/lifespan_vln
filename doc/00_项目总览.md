# 项目总览

本文档是本项目的总入口，概述研究目标、系统组成、运行主线和推荐阅读顺序。

## 1. 项目定位

本项目面向同一家庭环境中的长期具身导航与目标搜索。它不只评测 agent 在单个静态场景中是否能找到目标，而是构建同一 HM3D 家庭场景在多个时间状态下的动态物体布局，并考察 agent 能否在跨 episode、跨 layout 的长期交互中积累和更新场景记忆。

核心问题：

```text
同一家庭环境
  -> 多个时间状态 layout
  -> 多模态目标任务
  -> 真实 Habitat RGB-D 闭环导航
  -> 远程开放词汇视觉感知
  -> Scene-level 长期记忆
  -> Agentic-RAG 候选检索与选点
  -> 长期能力评测与可视化诊断
```

## 2. 系统主线

当前主线流程如下：

```text
HM3D 场景 + 动态物体资产
  -> 生成动态 layout
  -> 构建 longterm_v1 benchmark episode
  -> 工作站运行 Habitat-Sim
  -> 服务器运行 GroundingDINO + MobileSAM + CLIP
  -> 工作站通过 HTTP/SSH tunnel 调用远程视觉
  -> RGB-D 观测反投影为 3D/2D 物体位置
  -> 更新 SceneMemory / RoomMemory
  -> RAG + Agent scoring 检索候选
  -> room-level planning 或 object-level planning 选点
  -> Habitat navmesh 真实路径执行
  -> 输出评测、诊断、HTML 和可选搜索视频
```

## 3. 主要能力

- 动态布局数据集：同一 scene 下多个时间状态，模拟家庭物体移动。
- 多模态任务：`open_vocab`、`image_goal`、`language_goal`。
- 远程开放词汇感知：GroundingDINO、MobileSAM、CLIP 在服务器运行。
- 长期记忆：按 scene 维护 object tracks、pseudo-room memory、负反馈和位置平滑。
- 导航选点：默认使用 room-level planning，保留 object Top-1 作为消融。
- 评测诊断：SR/SPL、found rate、GHR@K、candidate recall、memory diagnostics。
- 可视化：HTML 2D/3D 调试、阶段性 memory timeline、subtask 级搜索视频。

## 5. 当前推荐入口

真实长期闭环主入口：

```bash
python -m RAANav.AgenticRAG.benchmark_adapter.run_temporal_habitat_loop
```

诊断入口：

```bash
python -m RAANav.AgenticRAG.benchmark_adapter.diagnose_temporal_run
```

HTML 可视化入口：

```bash
python -m RAANav.AgenticRAG.benchmark_adapter.visualize_temporal_run
```

远程视觉服务入口：

```bash
bash remote_vision_server/run_server.sh
```
