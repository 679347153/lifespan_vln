## 关系簇含义：
### 关系簇偏移可能的原因
> 关系簇区域扩张算法改为“匀速外扩”，不再按距离比例缩放，避免整体形状被拉伸造成视觉漂移与旋转错觉。
默认关闭原来的碰撞解决（它会移动簇导致位置偏移），新增可选“启用防重叠微调”复选框；只有开启才尝试轻量 AABB 分离。
保留原房间/簇凸包或矩形逻辑，位置现在应与节点真实位置对齐。
新 flag region_no_overlap 通过 force_multipliers 传入; 关闭时不做任何平移。
请刷新运行并在 **未勾选“启用防重叠微调”** 下查看区域是否与对象对齐。若仍有少量旋转/错位，可再加入代码：使用对象点集直接绘制（不扩张）或改成最小面积旋转矩形。


在层级视图“区域标记”里，关系簇表示：同一房间内，通过对象之间 Rcfd 关系（功能/语义关联）形成的紧密子群（可能再细分）。它用于突出“这几个对象在语义/功能上互相关联”的局部团块，区别于物理房间区域。

判定流程（对应 `build_multi_hierarchy_3d_figure` 中的代码）：
1. 收集对象关系边：遍历所有当前纳入的对象，对其 R_objs；过滤 Rcfd < min_rcfd 的边。
2. 自适应阈值 adaptive_thresh = max(min_rcfd, 0.15)（保证过低的全连接噪声被抑制）。
3. 按房间分组：只在同一房间内部做聚类（跨房间不形成簇区域）。
4. 对每个房间：
   - 建无向图 RG（对象为节点，保留 Rcfd ≥ adaptive_thresh 的边）。
   - 若没有任何边：每个对象作为单节点簇（仅用于后续布局吸引；渲染阶段 size<2 的簇不会生成区域多边形）。
   - 否则取 RG 的连通分量。
   - 对于大小 > 6 的连通分量，尝试 greedy_modularity_communities 细分：
     - 有效子社区（|C|>1）各自成为簇；残余单节点各自独立。
     - 若细分失败或无意义，保持原连通分量。
5. 给每个对象记录其 cluster id；同时统计同簇内部边的 Rcfd 均值 → 得到 cluster_avg_rcfd（热度 0~1）。

区域多边形生成：
1. 收集簇内成员对象在当前力布局后的 (x,y) 平面坐标（对象层 z 被忽略）。
2. 只对 |簇|≥2 生成区域；单节点簇跳过（避免视觉噪点）。
3. 形状：
   - 若 “区域形状”=“矩形”：用成员点的 min/max 包围盒。
   - 若 选择“凸包”：用简化 Graham scan 求凸包。
4. Padding：pad_base_cluster = 0.4 + 0.12*cluster_attr_mul + 0.1*rep_mul（聚合/斥力倍率越大，扩张越多），再对多边形做质心径向放大 expand_poly。
5. 写入 regions 列表：('cluster', cluster_id, z_offset, polygon)，z_offset = objects 层 z - 0.08（略微上浮，避免与对象点重合）。
6. 碰撞避让：与房间区域一起做 AABB 碰撞迭代 20 轮：
   - 房间区域保持静止；cluster 区域若重叠则沿最小分离方向平移（cluster-cluster 对半移动）。
7. 过滤显示：若用户关闭“关系簇区域”则跳过。

颜色与渲染：
1. 颜色梯度：蓝(41,128,185) → 橙(255,87,34)，按 avg_rcfd 线性插值。
2. 填充：Mesh3d（使用多边形顶点投影成一个水平面）+ opacity=region_opacity（可调）。
3. 边框：Scatter3d 线条；cluster 边框使用虚线 (dash='dot')。
4. 透明度：簇填充略提升 +0.05 上限 0.6，线框不透明度固定 0.85。
5. 房间区域与簇区域可分别开关；房间区域颜色直接复用房间调色板（之前已改）。

与布局/力模型互动：
- cluster_attr_scale：增大 → 簇内对象更集中，区域更紧凑。
- cluster_rep_scale：增大 → 簇与簇更疏远。
- repulsion_scale：影响 padding 计算 & 同层排斥，间接影响区域扩散。
- min_rcfd：提高 → 低强度边被过滤 → 簇可能拆分为更多小簇或单对象（单对象不绘制区域）。

常见现象说明：
- 某些对象不在任何可见簇区域：可能簇大小=1（被跳过）或 Rcfd 边都低于阈值。
- 簇颜色偏蓝：平均 Rcfd 低；可调低 min_rcfd 或增大 cluster_attr_scale 聚合提升局部密度。
- 区域挤压错位：碰撞迭代基于 AABB，复杂 concave 形状可能仍部分重叠，可尝试“凸包”形状或调小 padding（降低聚合/斥力倍率）。

快速调试建议：
- 先关闭“房间区域”只看簇区域层次。
- 调高最小 Rcfd 观察高强度簇分布，再逐步降低了解扩展。
- 开启动画（低帧数/较高 cooling=0.95）观测簇收敛动态。

若需：显示单节点簇区域 / 导出簇 JSON / 更复杂社区算法（Louvain）/ 颜色自定义，可继续说明。需要实现我再补。

# 语义地图 3D 可视化 (visual README)

简洁、全面地说明本应用的功能、交互与技术实现，方便快速上手与二次开发。


## 1. 功能概览
本应用基于 JSON 语义地图数据，提供两个核心 3D 视图：
1. 3D 平面组合视图：多楼层/房间/对象叠加展示（真实空间结构 + 对象 footprint + 关系线）。
2. 3D 层级关系视图：Building → Floor → Room → Object 跨层级力导图 + 对象关系簇聚合 + 区域蒙板。

支持：
- 楼层 / 房间 / 对象 多层级选择与组合渲染
- 对象间 Rcfd 关系过滤与着色 (灰→红)
- 主对象 vs 关系衍生 ghost 对象的差异化显示
- 房间与对象 footprint 多边形填充 + Mesh3d
- 房间调色板 + 对象类别调色板（自动缓存复用）
- 自适应或可自定义的垂直层级间距
- 关系簇检测（连通 + 可细分 modularity）与热度着色 (蓝→橙)
- 区域蒙板：房间区域 / 关系簇区域 可独立开关、形状（矩形 / 凸包）
- 自定义力模型倍率（对数滑杆 0.05~100）+ 动画迭代快照回放
- 参数保存 / 恢复 / 重置
- 平面视图：可调楼层垂直间距、对象平面高度比例、节点大小

```

      "floor_id": "F1",

      "rooms": [

              "obj_id": "O1",
              "label": "chair",
              "region": [{"x":..,"y":..},...],
              "R_objs": {"O2": {"Rcfd": 0.42}, ...},
              "N": 12, "stability": 0.73, "description": "..."
            }
          ],
          "door_positions": [...],
          "N": 5, "description": "..."
        }
      ]
    }
  ]
}
```
未提供的字段使用默认或忽略；`region` 多边形需顺时针或逆时针给出。

## 4. 交互控件速览

| 元素 | 含义 | 配色 / 样式 |
| ---- | ---- | ----------- |

## 6. 力模型一览 (层级视图)
迭代模拟 (默认 ~90–300 步，节点数自适应)：
- 同层斥力：防止同层聚堆
- 父子重力/吸引：保持层级聚合
- 房间内部聚合：微收敛对象
- 关系簇聚合 + 热度权重：同簇对象更集中
- 关系边微调：保持互相关联对象距离合理
- 簇间斥力：簇与簇分离
- 全局重力：防止整体漂移
- 垂直间距缩放：整体层间拉伸 / 压缩
- 退火 (冷却系数)：迭代后期平滑稳定

---
## 7. 区域生成逻辑
1. 收集对象平面坐标 → 按房间/关系簇聚合
2. 形状：矩形外包框或凸包
3. 动态 padding：随聚合/斥力倍率调整
4. Cluster 区域与房间区域间做 AABB 迭代位移避让（房间固定）
5. 最终作为 Mesh3d + 线框叠加于对应 Z 层偏移

## 10. 常见问题 (FAQ)
Q: 页面空白 / 无图？
A: 确认 JSON 路径正确；或刷新后检查终端是否有异常输出。

Q: 区域蒙板无变化？
A: 确认已勾选“标记区分区域”且对应子开关(房间区域/关系簇区域)开启。

Q: 关系簇颜色不明显？
A: 适当提高最小 Rcfd 过滤或增大“关系簇聚合”倍率让簇更紧凑。

Q: 动画卡顿？
A: 减少帧数 / 增大抓帧间隔 / 关闭动画后再调参数。

## 12. 对比 & 差异高亮 (新增)
在侧栏勾选 “并排对比 (history vs now)” 后：
- 左侧渲染历史 (map_history)；右侧渲染当前 (map_now)。
- 对象差异自动分类：added / removed / moved / changed / same。
  - 位置/移动判断使用“移动判定阈值(m)”滑杆 (默认 0.25m) 对质心 dx 或 dy 超过阈值判定 changed。
  - 楼层或房间变化判定为 moved。
- 颜色：
  - 新增(added)=绿色(#2ca02c)
  - 删除(removed)=红色(#d62728)；若勾选“ghost 标记”则在当前视图中克隆显示 label 前缀 (del)
  - 移动(moved)=橙色(#ff7f0e)
  - 属性/位置细微变化(changed)=紫色(#9467bd)
  - 其它 same 保持默认类别色 (平面) 或层级模式策略色。

### ghost 删除对象
勾选“在当前视图中以 ghost 标记历史已删除对象”会把历史中存在但当前缺失的对象以 (del)+label 形式克隆进右侧对应房间，并打上 `_deleted` 标志，稳定度强制 0。便于空间对比。

### 自动相机镜像
勾选 “启用相机同步 (试验)” 后：
- 平面视图：左侧出现“自动镜像相机 (左驱动→右)” 复选框；开启后你在左图旋转/缩放操作完成后下次重绘会把最新 camera 应用于右图。
- 层级视图：同理有 “自动镜像相机 (层级 左→右)”。
- 当前实现使用 `streamlit-plotly-events` 捕获用户交互后返回的图配置，从 layout.scene.camera 取出并同步；若初次交互未触发，可轻微拖动一次使其捕获。

### 性能提示
- 双图 + 事件捕获会增加重绘次数，节点较多时如出现卡顿可暂时关闭自动镜像或对比模式。
- 若出现多个重复图像，可能是缓存未命中或浏览器多次 rerun；已经重构为每侧一次渲染，旧版本残留可强制刷新 (Ctrl+F5)。
