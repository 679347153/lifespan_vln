# 语义地图 2D 编辑器使用说明

本文件说明 `editorApp.py` 的功能与操作，重点区分“编辑模式”与“只读模式”。

## 一、启动
```bash
streamlit run editorApp.py
```

## 二、加载与保存
- 左侧输入原始 JSON 路径 (默认 `RAG_Graph/map_now.json`) 点击【加载】。
- 编辑后使用【另存为】输出到自定义文件名 (不会覆盖原始)。

## 三、模式切换
侧边栏“模式”区：
- 编辑：画布坐标范围锁定，禁止鼠标缩放/平移，保证新增/移动对象时坐标稳定；标题显示 `[编辑锁定]`。
- 只读：可鼠标拖拽平移、滚轮缩放（scrollZoom 打开），标题显示 `[只读自由缩放]`。若勾选“锁定当前计算范围”，则即使缩放也会强制回到锁定范围。

切换模式不会清空数据。编辑完成后可切换到只读模式进行整体浏览。

## 四、查看范围 (room / floor)
- room：仅当前房间。用于细粒度新增对象、关系编辑、多边形绘制。
- floor：整层所有房间透明叠加（房间轮廓半透明），可用“新增房间”在最右侧追加一个矩形房间并自动放置。

## 五、对象颜色
按照 `label` 分配稳定的分类调色板 (离散 15 色循环)。同类标签同色。选中对象用红色 (#d62728) 标识；批量选中使用紫色 (#9467bd)。

## 六、对象选择与批量操作
- 单对象下拉选择后在“对象编辑”区可平移 / 删除 / 复制。
- 批量选择列表可多选对象，输入 dx/dy 点击【应用批量平移】。
- 复制对象会自动生成新 ID，并在原位置基础上平移 (0.2,0.2)。

## 七、对象新增
仅在“编辑”模式显示：
1. 矩形：输入中心 (cx,cy) 与 (w,h)。
2. 多边形：选择“多边形(点击绘制)”后，在画布点击添加点；完成后点击【完成多边形】。

支持网格吸附：勾选“启用网格吸附”并设置网格大小 (默认 0.25)。

## 八、新增房间 (整层视图)
切到 floor 视图后在“新增房间”区：
- 输入房间 ID、宽高，点击【添加房间】。
- 系统计算整层现有房间包围盒，把新房间放置在最右侧并水平居中。

## 九、关系 (R_objs) 编辑
在“对象编辑”区：
- 已有关系逐条显示，可单独删除。
- 选择目标对象并填写 Nt/Nr/Rcfd 后点击【添加/更新关系】。
- 仅 room 视图显示关系连线；连接颜色由 Rcfd 灰→红梯度，线宽与 Rcfd 成正相关。

## 十、撤销 / 重做
- 操作前自动 push 到 undo 栈 (最多 40 条)。
- 支持【撤销】与【重做】按钮；多边形点添加也可撤销。

## 十一、视图范围与锁定
- 初次根据当前对象/房间自动计算包围盒并留 padding。
- 勾选“锁定当前计算范围”后保存当前范围到会话；
  - 编辑模式：固定范围 + 禁用平移缩放。
  - 只读模式：若锁定则使用固定范围，未锁定则自由缩放。
- “保持等比例”用最大边统一扩展，避免图形因比例失真。

## 十二、右侧信息面板
主图右侧显示当前选中对象信息：ID / Label / 所属房间 / 质心 / 关系数。只读模式下提示“只读模式”。

## 十三、3D 预览
侧边栏勾选“显示简化 3D 预览区”可渲染全部楼层简化 3D 结构 (复用 `visualizeApp` 的构建函数)。

## 十四、常见问题 (FAQ)
1. 为什么编辑模式不能缩放？
   - 为保持坐标稳定，不因用户缩放导致新增点或矩形输入判断偏移。需要查看整体时切到只读模式。
2. 想要在编辑模式下暂时改变视图怎么办？
   - 先切换到只读进行缩放确定好视野，然后勾“锁定当前计算范围”再切回编辑。
3. 多边形绘制误点？
   - 可以【撤销】或在多边形面板点“重置点”。
4. 想删除一个复制出来的对象？
   - 选中后点击“删除对象”。
