## 4. 可能的问题分支

如果诊断结果为 `retrieval_no_candidates`：

- 检查 `observation_traces.jsonl` 中是否有 detection。
- 检查 detection 是否带 `clip_embedding_dim`。
- 检查目标 label 是否出现在 prompt label 列表或 memory 中。
- 尝试降低或显式设置 `--clip-min-score 0.15` 到 `0.2`，提高远程 CLIP text-image 召回。

如果诊断结果为 `candidates_far_from_goal`：

- 检查 `candidate_traces.jsonl` 中 top candidates 的 label、`sim_backend`、`S_final` 和目标距离。
- 增强 alias 与 target object 的规范化，避免目标名和检测名错配。
- 检查 `scene_memory_final.json` 中同类物体是否持续停留在旧 layout 位置。
- 分析 negative feedback 是否有效降低旧位置权重。

如果诊断结果为 `candidate_near_but_navigation_or_success_radius_failed`：

- 将 `--max-steps-per-subtask` 提高到 `80`。
- 将 `--max-rounds` 提高到 `5`。
- 将 `--micro-steps-per-round` 提高到 `8`。
- 检查最终观测是否因为视角、遮挡或检测阈值未确认目标。

如果诊断结果为 `perception_empty` 或 `memory_not_updated`：

- 检查远程服务健康状态：

```bash
curl http://127.0.0.1:50220/health
```

- 检查单图检测和 CLIP：

```bash

  --base-url http://127.0.0.1:50220 \
  --image objects_images/Camera_01.webp \
  --text chair \
  --return-clip-embedding \
  --clip-query-text chair
```
