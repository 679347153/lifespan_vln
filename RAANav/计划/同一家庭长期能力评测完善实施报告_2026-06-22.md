> 日期：2026-06-22  
> 目标：把远程感知 smoke test 的问题修正为可诊断、可检索、可消融、可长期评测的工程闭环。

## 1. 本次完成内容

### 1.1 远程 CLIP 文本-图像检索闭环

已在远程视觉服务中新增：

```text
POST /v1/clip/text_image_similarity
```

能力：

- 输入文本查询和一组图像 `clip_embedding`。
- 在服务器上使用同一个 CLIP 模型计算 text embedding。
- 返回 text-image cosine similarity top-k。
- 当工作站禁用本地 CLIP 时，legacy 导航脚本仍可进行 CLIP 检索，而不是只能 label 精确匹配。

相关文件：

```text
remote_vision_server/server.py
remote_vision_server/client.py
remote_vision_server/test_client.py
```

### 1.2 legacy Habitat smoke test 诊断修正

已修改：

```text
RAANav/AgenticRAG/scripts/z_legacy/legacy_gdino_frontend/sim_nav_loop_gdino.py
```

行为变化：

- 使用 remote perception 且未指定本地 CLIP 时，自动启用服务器端 CLIP。
- `_clip_search_in_memory()` 在本地 CLIP 禁用时优先调用远程 text-image similarity。
- 默认远程 CLIP 文本检索阈值为 `REMOTE_VISION_CLIP_TEXT_MIN_SCORE=0.65`。
- 远程 CLIP 失败时才 fallback 到 label 精确匹配。

### 1.3 smoke 输出诊断工具

新增：

```text
RAANav/AgenticRAG/benchmark_adapter/diagnose_nav_smoke.py
```

用途：

- 读取 legacy 导航输出目录。
- 汇总地图中真实出现过的 label。
- 推荐下一次 smoke test 的 target。
- 判断当前 target 是否根本没有被观测到。
- 检查是否产生 query_step 诊断产物。

示例：

```bash
python -m RAANav.AgenticRAG.benchmark_adapter.diagnose_nav_smoke \
  --output-dir RAANav/AgenticRAG/RAG_Graph/remote_vision_nav_smoke \
  --target chair
```

## 2. 推荐验证命令

### 2.1 远程 CLIP 单图检索验证

```bash
python remote_vision_server/test_client.py \
  --base-url http://127.0.0.1:50220 \
  --image objects_images/Camera_01.webp \
  --labels "chair,table,sofa,bed,cabinet,lamp" \
  --return-clip-embedding \
  --clip-query-text "chair" \
  --clip-min-score 0.65
```

验收：

- detection 中 `clip_embedding` 非空。
- `clip_text_image_similarity.results` 非空，或明确显示没有相似目标。

### 2.2 legacy smoke test

先跑一个较长 smoke：

```bash
cd RAANav/AgenticRAG

  --scene-dir ../../hm3d/minival/00808-y9hTuugGdiq \

  --max-steps 30 \
  --n-views 4 \
  --perception-backend remote \
  --remote-vision-base-url http://127.0.0.1:50220
```

再诊断输出：

```bash
cd ../..
```
