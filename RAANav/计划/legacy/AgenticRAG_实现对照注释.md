## 二、逐项详细说明

### II-1: 负向高斯核步数衰减 (🆕 创新, 超出规范 §4.4.2)

**规范**: 负向高斯核一旦注入即**永久存在**, 公式中没有衰减项.

**实现**:
```python
# NegativeGaussianField.__init__()
self.decay_rate = math.log(2) / max(1, decay_halflife_steps)  # 默认 halflife=10 步

# NegativeGaussianField.apply() 中每个核的有效权重:
effective_alpha = k["alpha"] * math.exp(-self.decay_rate * age)
# age = current_step - k["inject_step"]
```

**效果**: 负核的惩罚强度随步数指数衰减, 半衰期约 10 步后降至原始强度的 50%.

**改动原因**:
1. **动态环境适应**: 在长期导航中, 物体可能被移动/遮挡/重新出现. 永久负核会导致 agent 永远不回头看, 即使环境已发生变化.
2. **"回心转意"机制**: 衰减允许 agent 在探索完其他区域后, 回到之前判定为"失败"的区域重新检查. 这在遮挡频繁的室内环境中非常关键.
3. **与规范精神一致**: 规范 §4.4 FAQ (Q4) 中提到"过度惩罚"的风险, 衰减是对这个风险的直接缓解措施.

**论文叙事建议**: 可作为"自适应负向反馈"的改进, 强调规范的静态负核在动态环境中的局限性, 以及衰减半衰期作为超参数的消融实验价值.

### II-2: 触发条件简化 (⚠️ 修改规范 §4.4.3)

**规范三条件**:
1. 视锥(frustum)完全覆盖物体 bbox_3d
2. 目标评分 $S(i) > \theta_{high} = 0.6$
3. 连续 miss ≥ 2 次

**实现**:
1. ~~视锥覆盖~~ → **距离检查**: `dist(agent, obj) < r_trigger` (默认 3.0m)
2. ~~$\theta_{high}=0.6$~~ → **阈值 = 0.0** (所有进入 watch_list 的物体均参与检测)
3. `miss_threshold = 2` ✅ **与规范一致**

**改动原因**:

**(条件 1) 视锥 → 距离**:
- 视锥-bbox 相交计算需要: 相机内参矩阵、物体 3D bbox 的 8 个顶点、视锥 6 面判定. 在 Habitat 中实现虽然可行, 但属于纯几何工程量, 对验证导航策略核心功能并非必要.
- 距离代理: 在 3m 半径内, 如果 GT 语义传感器看不到物体, 说明物体确实不在视野中 (遮挡/不存在). 这是一个合理的简化, 不会引入假阳性.
- **后续**: §Phase 1 Sim2Sim 多视角感知实现后, 可升级为视锥方案.

**(条件 2) θ_high=0.6 → 0.0**:
- 当前评分管线仅使用 CLIP 向量余弦相似度, **没有** agent_Rscore (LLM) 加成, 因此 self_score 典型值仅为 **0.03–0.05**.
- 如果保持 θ_high=0.6, 则 **不会有任何物体进入 watch_list**, 负向机制完全失效.
- 阈值 0.0 的含义: 只要物体被 CLIP 检索命中 (出现在 watch_list 中), 就参与假阴性检测. 这是一个合理放宽, 因为 CLIP 检索本身就是初筛.
- **后续**: 当 agent_Rscore + 全流程评分实现后, 应恢复 θ_high=0.6.

### II-3: 访问密度场 (🆕 创新, 规范中没有)

**规范**: 没有任何关于"已访问位置惩罚"的内容. 规范假设负向高斯核足以引导探索.

**实现**:
```python
# frontier_exploration_step() 中:
visit_density = np.zeros((H, W))
visit_sigma_px = 2.0 / resolution  # σ = 2m
for vp in visited_positions:
    visit_density[r0:r1, c0:c1] += gaussian(...)  # 不归一化, 原始累积

# GMM 引导模式: 概率场减去访问密度惩罚
beta = prob_max / 3.0  # 3 次访问 → 峰值完全抑制
score = prob_corrected - beta * visit_density
```

**关键设计决策**: 访问密度**不归一化** (原始累积值).

**改动原因**:
1. **解决"原地踏步"问题**: 负向高斯只针对**语义上的假阴性** (看不到特定物体), 但不阻止 agent 反复经过同一空间位置. 在实测中, agent 会在两个高概率点之间来回震荡 (18 步卡在同一位置).
2. **不归一化的原因**: 归一化到 [0,1] 后, 单次访问的惩罚极其微小 (因为访问点少, 归一化后密度值很小), 实际不起作用. 不归一化意味着每次访问真实累加一个 σ=2m 的高斯, **3 次访问后惩罚 ≈ prob_max**, 有效抑制重复访问.
3. **σ = 2m 的含义**: 每次访问"影响"周围 2m 半径, 这约等于一个典型室内物体的感知范围, 确保 agent 不会反复搜索相同的小区域.
4. **β = prob_max / 3**: 这意味着一个峰值需要大约 3 次访问才能被完全抑制, 允许 agent 在高概率区域进行必要的多次确认, 但不至于无限循环.

**论文叙事建议**: 可描述为"空间探索覆盖保证", 与负向高斯的"语义反馈驱动"形成互补的双层机制.

### II-4: Frontier 回退模式 (🆕 创新, 规范中没有)

**规范**: 仅描述 GMM 概率场 → Top-K 探索点. 没有处理"概率场变平"的情况.

**实现**:
```python
# frontier_exploration_step() 中:
is_flat = (prob_max < 1e-10) or (prob_max / prob_mean < flatness_ratio)  # 默认 3.0

if is_flat:
    score = -visit_density.copy()  # 去最少访问的地方
    mode = "frontier"
else:
    score = prob_corrected - beta * visit_density
    mode = "gmm"
```

**改动原因**:
1. **概率场退化**: 当多个负向核覆盖了所有高概率区域后, 概率场变成近乎均匀分布 (max/mean → 1). 此时 GMM 引导失去意义.
2. **Frontier 是成熟策略**: Frontier-based exploration 是机器人探索的经典方法 (Yamauchi 1997), 在 BeliefMapNav 等参考项目中也有使用. 作为退化情况的 fallback, 是合理且有理论支撑的选择.
3. **三层决策层级**: 最终形成 `GMM 引导 → 负向修正 → Frontier 回退` 的三层策略, 比单纯的 GMM 更鲁棒.

**触发条件**: `flatness_ratio = 3.0` — 当概率场最大值不超过均值的 3 倍时, 认为场"拾平坦", 切换模式.

### II-5: 负核生命周期管理 (🆕 创新, 规范中没有)

**规范**: 没有关于负核清理/删除的内容.

**实现**:
```python
# NegativeGaussianField.cleanup()
def cleanup(self, current_step: int, max_age: int = 50):
    self.kernels = [k for k in self.kernels if current_step - k["inject_step"] < max_age]
```

**改动原因**: 
1. **内存管理**: 长时间运行中, 如果不清理, 核列表会无限增长. 超过 50 步的核衰减后有效强度 < 3% (因为 halflife=10 步, 50 步后 $2^{-5} \approx 3\%$), 对概率场影响微乎其微.
2. **计算效率**: 每步 apply() 遍历所有核, 清理过期核可减少不必要的计算.
